# Introduction

시계열 예측 모델은 주로 RNN이나 Transformer처럼 복잡한 sequence model을 사용해 왔다. 하지만 LTSF-Linear는 여러 장기 시계열 예측 benchmark에서 단순한 선형 모델이 Transformer 계열 모델보다 좋은 성능을 보일 수 있음을 제시했다. 이 결과는 복잡한 모델이 항상 시계열의 temporal pattern을 더 잘 학습하는 것은 아니라는 의문을 만든다.

TSMixer는 이 관찰에서 출발한다. 선형 모델이 가진 시간축 학습 능력은 유지하면서, MLP를 통해 모델의 표현력을 높이고 multivariate time series의 cross-variate information까지 활용하는 것이 목표다.

논문은 시계열의 예측 가능성을 다음 세 종류의 정보에서 찾는다.

1. `Temporal pattern`: trend, seasonality처럼 시간에 따라 지속되는 패턴
2. `Cross-variate information`: 서로 다른 변수 사이의 관계
3. `Auxiliary information`: 위치·상품 종류 같은 static feature와 미래의 프로모션처럼 미리 알 수 있는 feature

기존 benchmark에서는 변수 간 관계가 약해 univariate model이 유리할 수 있지만, 실제 수요 예측에서는 가격·프로모션·상품 정보처럼 변수 간 관계가 중요하다. TSMixer는 이 두 상황에서 모두 안정적으로 동작하는 단순한 all-MLP architecture를 제안한다.

```text
Historical time series
        ↓
[Time mixing → Feature mixing] × N
        ↓
Temporal projection
        ↓
Forecasted time series
```

# Why Linear Models Work

입력 시계열을 $X \in \mathbb{R}^{L \times C}$라고 하자. $L$은 lookback window 길이이고 $C$는 변수의 수다. $T$개 미래 시점을 예측하는 temporal linear model은 각 변수에 동일한 선형 변환을 적용한다.

$$
\hat{Y} = AX \oplus b,
$$

여기서 $A \in \mathbb{R}^{T \times L}$이며, $\oplus$는 각 변수에 bias를 더하는 연산이다. 이 구조는 각 입력 시점마다 고정된 weight를 가진다. 논문은 이를 `time-step-dependent` model이라고 표현한다.

반면 LSTM의 gate나 Transformer의 attention weight는 입력값에 따라 달라지는 `data-dependent` mapping이다. 표현력은 더 크지만, 데이터가 충분하지 않거나 변수 간 관계가 약한 benchmark에서는 불필요한 패턴까지 학습해 overfitting할 수 있다.

## Periodicity and smoothness

주기가 $P$인 시계열은 $P$ 시점 전의 값을 선택하는 선형 weight만으로 미래 값을 정확히 복사할 수 있다. 논문은 이를 smooth trend가 더해진 경우로 확장한다.

$$
x(t) = g(t) + f(t),
$$

여기서 $g(t)$는 주기 $P$를 가진 신호이고 $f(t)$는 Lipschitz constant $K$를 가진 smooth function이다. $L \geq P+1$인 lookback window가 주어지면 다음 오차 한계를 만족하는 선형 모델이 존재한다.

$$
|y_i - \hat{y}_i| \leq K(i + \min(i, P)).
$$

이 결과가 모든 실제 시계열에 대한 보장은 아니다. 다만 주기성과 완만한 trend가 강한 데이터에서, 위치별 고정 weight를 사용하는 선형 모델이 강력한 baseline이 되는 이유를 설명한다.

# TSMixer Architecture

TSMixer는 $X \in \mathbb{R}^{L \times C}$의 두 축을 번갈아 처리한다.

- `Time mixing`: 각 변수 내부의 temporal pattern 학습
- `Feature mixing`: 같은 시점에서 서로 다른 변수 사이의 관계 학습

두 연산의 weight는 각각 반대쪽 축을 따라 공유된다. Time-mixing MLP는 모든 변수에 같은 temporal transformation을 사용하고, feature-mixing MLP는 모든 시점에 같은 feature transformation을 사용한다. 전체 입력을 하나의 거대한 vector로 펼치는 것보다 parameter를 효율적으로 사용할 수 있다.

## Time-mixing MLP

Time mixing은 입력을 transpose한 뒤 각 변수의 $L$개 시점에 fully-connected layer를 적용한다. 개념적으로 변수 $c$에 대한 연산은 다음과 같다.

$$
\operatorname{TM}(X)_{:,c}
= \operatorname{Norm}\left(
X_{:,c} + \operatorname{Dropout}\left(
\sigma(W_t X_{:,c} + b_t)
\right)\right).
$$

$W_t$와 $b_t$는 모든 변수에 공유된다. 하나의 linear layer, activation, dropout, residual connection으로 구성되며 특정 변수만을 위한 별도 temporal model을 만들지 않는다.

## Feature-mixing MLP

Feature mixing은 각 시점의 $C$개 변수를 함께 입력받는다. 시점 $t$에 대한 연산은 다음과 같이 나타낼 수 있다.

$$
U_{t,:} = \operatorname{Dropout}\left(
\sigma(W_1 X_{t,:} + b_1)
\right),
$$

$$
\operatorname{FM}(X)_{t,:}
= \operatorname{Norm}\left(
X_{t,:} + \operatorname{Dropout}(W_2 U_{t,:} + b_2)
\right).
$$

Feature mixing은 두 개의 linear layer로 구성되며 모든 시점에 weight를 공유한다. 센서나 변수 사이의 상관관계가 유용하면 이 block이 이를 학습한다. 반대로 관계가 불필요하면 residual path를 통해 feature mixing의 영향을 작게 만들 수 있다.

## Mixer layers and temporal projection

Time-mixing과 feature-mixing block을 하나의 mixer layer로 묶어 $N$번 반복한다. 각 block의 residual connection은 깊은 모델의 학습을 돕는 동시에 불필요한 mixing operation을 건너뛸 수 있게 한다.

마지막에는 temporal projection이 입력 길이 $L$을 예측 길이 $T$로 변환한다.

$$
\hat{Y}_{:,c} = W_p O_{:,c} + b_p,
$$

여기서 $O$는 마지막 mixer layer의 출력이다. 논문은 time과 feature 두 차원을 모두 다루므로 일반적인 feature-wise normalization 대신 두 축을 고려한 normalization을 사용한다. 장기 예측 실험에서는 distribution shift를 완화하기 위해 RevIN도 적용한다.

## TMix-Only

`TMix-Only`는 feature mixing을 제거한 ablation model이다. 각 변수를 독립적으로 처리하므로 univariate model에 가깝지만, 여러 time-mixing MLP를 쌓아 단일 선형 모델보다 높은 capacity를 가진다.

이 모델은 두 가지를 확인하기 위해 사용된다.

1. Temporal linear layer를 비선형 MLP로 쌓는 것이 유효한가?
2. 해당 데이터에서 cross-variate information이 실제로 도움이 되는가?

# Extended TSMixer

실제 예측 문제에는 과거 target 이외의 정보가 함께 주어질 수 있다.

- Historical features $\hat{X} \in \mathbb{R}^{L \times C_x}$
- Future features $Z \in \mathbb{R}^{T \times C_z}$
- Static features $S \in \mathbb{R}^{1 \times C_s}$

TSMixer-Ext는 길이가 다른 입력을 먼저 같은 시간 길이와 hidden dimension으로 projection한다. Static feature는 시간축으로 반복하고, historical feature는 prediction length로 변환한다. 정렬된 feature를 concatenate한 뒤 mixer layer를 적용하면 과거 정보, 미래에 알려진 정보, static information 사이의 관계를 feature mixing으로 함께 학습할 수 있다.

최종 layer는 point forecast를 직접 출력할 수도 있고 확률 분포의 parameter를 출력할 수도 있다. M5 수요 예측에서는 판매량에 0이 많다는 특성을 고려해 negative binomial distribution을 학습한다.

# Experimental Results

## Long-term forecasting benchmarks

ETTh1, ETTh2, ETTm1, ETTm2, Weather, Electricity, Traffic의 7개 dataset을 사용한다. 입력 길이는 $L=512$, 예측 길이는 $T \in \{96, 192, 336, 720\}$이며 MSE와 MAE로 평가한다.

논문이 보고한 baseline 대비 TSMixer의 전체 평균 MSE 개선율은 다음과 같다. 양수는 TSMixer가 더 좋고 음수는 TSMixer가 조금 낮다는 의미다.

| Baseline | TSMixer MSE improvement |
| --- | ---: |
| TFT | 51.94% |
| FEDformer | 16.69% |
| Autoformer | 24.51% |
| Informer | 62.40% |
| TMix-Only | -0.66% |
| Linear | 6.77% |
| PatchTST | -1.53% |

TSMixer는 기존 multivariate Transformer 계열보다 좋은 결과를 보였지만 TMix-Only, Linear, PatchTST와는 비슷했다. 즉, 이 benchmark에서는 feature mixing의 추가 이득이 거의 없다. 논문은 이를 architecture의 실패보다는 변수 간 정보가 충분히 유용하지 않은 benchmark의 특성으로 해석한다.

Lookback window 실험에서는 linear model이 $L=96$에서 $336$으로 증가할 때 크게 개선되고, TSMixer는 $L=336$ 또는 $512$에서 가장 좋은 결과를 보인다. 긴 입력에서 overfitting이 발생하기 쉬운 일부 multivariate Transformer와 달리, TSMixer는 $L=720$에서도 비슷한 성능을 유지한다.

## M5 demand forecasting

M5는 Walmart의 상품 판매량을 예측하는 대규모 dataset이다. 30,490개 시계열과 함께 가격, 매장, 상품 분류, 달력, 프로모션 등의 정보가 제공된다. 이 설정에서는 변수 간 정보와 auxiliary feature가 실제로 중요하다.

Historical feature만 사용한 실험의 test WRMSSE는 다음과 같다. 낮을수록 좋다.

| Model | Multivariate | Test WRMSSE |
| --- | :---: | ---: |
| Linear |  | 0.983 |
| PatchTST |  | 0.976 |
| TMix-Only |  | 0.960 |
| Autoformer | ✓ | 0.742 |
| FEDformer | ✓ | 0.804 |
| TSMixer | ✓ | **0.737** |

일반적인 장기 예측 benchmark와 달리 M5에서는 multivariate model이 univariate model보다 큰 폭으로 우수하다. Cross-variate information이 실제로 존재할 때 feature mixing이 효과를 보인 결과다.

Static feature와 future feature를 모두 사용하면 TSMixer-Ext는 test WRMSSE `0.640`을 기록해 TFT의 `0.670`, DeepAR의 `0.789`보다 좋은 결과를 보인다. Parameter 수도 TSMixer-Ext가 약 244K로, DeepAR의 1M과 TFT의 2.9M보다 작다. 단, TFT는 다른 framework로 구현되어 있어 실행 시간 비교는 참고용으로 보는 것이 적절하다.

# Discussion

TSMixer의 중요한 점은 attention을 MLP로 단순 교체한 것보다 temporal information과 cross-variate information을 분리해서 다룬다는 데 있다.

- Time mixing은 선형 모델의 time-step-dependent inductive bias를 유지한다.
- Feature mixing은 변수 간 관계가 있을 때 이를 활용한다.
- Residual connection은 feature mixing이 필요하지 않은 데이터에서도 univariate model에 가까운 동작을 가능하게 한다.
- 구조가 단순해 구현과 inference가 비교적 가볍다.

반면 다음과 같은 한계도 있다.

- Linear model에 대한 분석은 periodicity와 smoothness 가정에 의존한다. 변동성이 크고 불규칙한 시계열에는 그대로 적용하기 어렵다.
- Temporal projection의 weight shape이 lookback length와 forecast horizon에 연결되므로 입력·출력 길이가 바뀌면 모델을 그대로 사용하기 어렵다.
- 일반적인 장기 예측 benchmark에서 TSMixer가 PatchTST나 TMix-Only를 일관되게 앞서지는 않는다.
- Cross-variate modeling의 가치는 dataset에 따라 크게 달라지므로 multivariate architecture를 평가할 benchmark 선택이 중요하다.

# Comment

복잡한 Transformer block 없이도 좋은 성능을 낸다는 결과보다, 변수 간 관계가 항상 유용한 것은 아니라는 실험이 더 흥미롭다. Academic benchmark에서는 TMix-Only와 TSMixer가 거의 같지만 M5에서는 multivariate model이 명확하게 좋아진다. 결국 모델의 복잡도보다 데이터에 실제로 존재하는 dependency를 architecture가 적절하게 선택할 수 있는지가 중요해 보인다.
